# v0.4.0 MVP Task List

## Working Agreement

- Complete one work package at a time unless two packages have a direct dependency.
- Keep backend, UI, and acceptance changes for the same workflow together.
- Do not begin Phase 4 retrieval work until the browser MVP acceptance criteria pass.
- Run the focused checks for a package before marking it complete.
- Use the fake LLM suite for deterministic CI and the real local model suite for acceptance.

### Backend

- [x] Phase 3 backend released as `v0.3.0`
