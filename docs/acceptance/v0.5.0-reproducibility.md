# v0.5.0 Clean-Tag Reproducibility Audit

Date: 22 July 2026

Status: Exact artifact reproduction failed; the published tag and accepted bundle were not mutated

## Scope

The audit rebuilt the application/worker and web images from a clean detached worktree at annotated
tag `v0.5.0`, commit `b0f51e3b5f0819beca9efddfe5780549ba6b5a9f`. The detached source tree contained
no generated caches. Docker build contexts excluded Git metadata, local environments, dependency
directories, and `var/`, but the current ignore rules do not reliably exclude nested Python caches
from a dirty source tree. Pinned base-image digests were used without pulling replacements. Existing
local BuildKit dependency layers were allowed, so this audit tests clean-source reconstruction but
does not claim cache independence.

The originally accepted images were preserved under local backup tags before the official `0.5.0`
tags were rebuilt. Syft `1.48.0` rescanned only the local Docker daemon with update checks disabled.

## Findings

The accepted application image was not built from the final committed tree. It contained 163
host-generated `.pyc`/`__pycache__` files and older copies of
`config/delivery/offline-bundle-v1.example.json` and
`config/native/vector-similarity-build-v0.5.0.json`. The clean rebuild contained the committed
versions of both files and no bytecode-cache files. All other non-cache `/app` file contents
matched. The native ABI-1 library matched exactly at
`e96f45b20bb7c637debe79fc8f692b582d357a80294b8df2d342e9e7afc4ad30`.

The web root filesystem, Nginx configuration, file modes, and layer chain matched exactly. Its
outer image identity and `docker save` archive still changed, demonstrating that the current
BuildKit attestation/export process is not a canonical identity boundary.

Both regenerated SBOMs retained the accepted package counts: 147 application packages and 72 web
packages. Package inventories matched except for the application image's OCI identity. Raw SPDX
hashes also changed because Syft emits a new creation timestamp and document namespace.

The tagged bundle specification failed closed before construction:

```text
bundle input checksum mismatch for images/application.tar:
expected 9770930977987c2e8368170a9c9ece8abc17716b06dfad9b8c4967a98f75d7d6,
found df9f95e6ac631b96ee88468c78174cdd5e8d1e41ec973b638bcf67c5ff713356
```

## Decision

The `v0.5.0` tag and its accepted bundle remain immutable historical evidence, but exact artifact
reproducibility is not accepted. Phase 9 must define a cache-independent build, prevent host cache
files from entering contexts, normalize or explicitly scope image/SBOM identities, and bind every
result to the source commit. Corrected artifacts must ship as a new patch release; `v0.5.0` must
not be moved or silently replaced.
