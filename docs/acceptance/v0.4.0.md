Date: 2026-07-13
Version: 0.4.0
Status: Accepted

## Scope

`v0.4.0` delivers the first integrated browser MVP on top of the Phase 3 RAG backend:

- Vue 3 authentication, document, streaming chat, source, conversation, and health workflows
- deterministic fake-provider browser testing and opt-in real-model acceptance
- production Nginx single-origin routing for the Vue application and FastAPI
- PostgreSQL, Redis, ingestion worker, API, and web health checks
- CPU and NVIDIA GPU model-service profiles with actionable startup failures
- isolated development, test, E2E, and production configuration profiles

## Deployment and Persistence

The production images were rebuilt before starting a dedicated Compose project with empty named
volumes. PostgreSQL, Redis, API, ingestion worker, and web services all reached healthy state.
The production browser suite then created this retained state:

```text
users=22 documents=6 conversations=4 messages=8 stored_files=8
```

After restarting every service and waiting for all health checks, every count was unchanged and
the reverse-proxy `/health` endpoint returned healthy. Operators must back up the Compose
`postgres_data` and `api_storage` volumes together. The `redis_data` volume retains queued jobs but
is not a substitute for PostgreSQL or document-file backups. `docker compose down` retains these
volumes; `docker compose down --volumes` destroys them.

## Known Limitations

- Browser tokens use session storage. Refresh tokens are stateless JWTs without server-side
  revocation; this release is not approved for unrestricted public hosting.
- Retrieval is dense pgvector cosine search only. Hybrid lexical retrieval, reranking, formal RAG
  evaluation, and quality thresholds begin in Phase 4.
- The real-model acceptance corpus is one small English document and proves integration, not answer
  quality, faithfulness, multilingual quality, or hallucination rates.
- Model artifacts and container images are not bundled for a fully air-gapped installation.
- Deployment is single-node and has no high-availability, automated backup, or restore workflow.
- Default model concurrency is one request. Throughput depends on the operator's CPU, GPU, model,
  context, and quantization choices.
- DOCX extraction does not preserve page numbers, and chunk token boundaries use whitespace spans
  rather than a model-specific tokenizer.
