# v0.5.0 Release Candidate Acceptance

Date: 20 July 2026

Status: Accepted locally; commit, merge, tag, and publication pending

## Scope

`v0.5.0` closes Phases 4–8 on top of the `v0.4.0` browser MVP. It includes the measured retrieval
and generation pipeline, adapter evaluation with adapter-free production retention, the accepted
Gemma 3 1B Q4 CUDA runtime, verified air-gapped delivery and recovery, and optional ABI-1 native
batch cosine with Python fallback.

No new model, adapter, or retrieval default was promoted during release closure.

## Local SBOM Closure

Syft `1.48.0` was downloaded from Anchore's immutable GitHub release and its Linux AMD64 archive
matched the published SHA-256
`6cef9a7f37220d9067eaf9cfaaa2fce986e9f320a8d42cbc36658c99af78ea04`. With update checks disabled,
it scanned only the local Docker daemon and produced SPDX 2.3 inventories for the exact candidate
images: 147 application packages and 72 web packages. No Docker Scout upload or remote indexing was
used.

The host did not contain Cosign or GitHub CLI, so the checksum proves downloaded-byte integrity but
not publisher authorship. Phase 9 WP9.2 retains publisher-signature verification as a required gate.

## Methodological Packaging Fixes

The full container suite initially exposed that shipped training CLI modules and configuration
manifests were omitted from the application image. After packaging `training/`, secret-free
`config/`, and pinned build-environment manifests, two remaining tests exposed a hidden `jq`
dependency in adapter activation. The startup script now uses a dependency-free Python JSON reader
already guaranteed by the application runtime.

No failure was waived. The final corrected image passed all 322 backend tests. Ruff, MyPy over 72
source files, 28 frontend tests across seven files, frontend type/build checks, Release CTest, and
AddressSanitizer/UndefinedBehaviorSanitizer CTest also passed.

## Clean Network-Denied Acceptance

A fresh path-isolated target started seven healthy services from the final bundle. The application
probe passed health, registration, login, upload, asynchronous ingestion, dense retrieval, grounded
local generation, persisted document, and persisted citation checks in `1.378` seconds.

Runtime inspection confirmed version `0.5.0`, native ABI 1, identical deliberate Python-fallback
scores, and the corrected packaged training/config/manifest-reader boundary. Network probes failed
closed:

| Probe | Accepted result |
| --- | --- |
| API direct connection to `1.1.1.1:443` | `OSError: [Errno 101] Network is unreachable` |
| API resolution of `example.com` | `socket.gaierror: Temporary failure in name resolution` |
| Web request to `https://example.com` | `wget: bad address 'example.com'` |

The runtime log scan contained only local listeners and calls to `llm:8080` and `embedding:8080`.
No download, telemetry, analytics, Sentry, Hugging Face, or external endpoint attempt appeared. Both
model servers and the remaining stack were stopped after acceptance; target evidence was preserved.

## Publication Boundary

The candidate is accepted locally, but it is not yet a published release. The source changes must
be reviewed and committed, the release branch must follow the repository's merge policy, and the
annotated `v0.5.0` tag must be created and pushed only after that commit is final.
